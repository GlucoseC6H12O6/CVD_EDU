## 수집 방법과 한계

- 웹 검색으로 서지와 요약을 확인했다. 논문 전문은 열람하지 못했다.
- **193 nm에서 가스 비(SiH₄/N₂O)에 따른 n, k 수치표를 찾지 못했다.** DARC의 광학 상수 실측값은 248 nm 특허 예 1건뿐이다. 본문의 DARC 설계는 원리와 계산 위주다.
- 검색 요약이 여러 출처를 묶어 서술한 경우 문장별 출처를 특정하지 못했다. 해당 항목은 그렇게 표시했다.
- 확인 수준: **A** 서지와 수치를 요약으로 확인 / **B** 서지(제목·존재)만 확인 / **C** 기억에 의존, 재확인 필요

## 4. 아직 비어 있는 자료

1. **193 nm DARC의 n, k 실측과 가스 비의 관계.** SPIE Litho 문헌에 있을 가능성이 높다.
2. **ACL 위 SiON(Hardmask 겸 DARC)의 공정 조건**과 ACL 계면 손상에 관한 공개 자료.
3. **응력과 조성의 관계**(S06 전문).
4. **Footing 대책별 효과 비교**의 정량 데이터.
5. S09(승계) 재확인.
